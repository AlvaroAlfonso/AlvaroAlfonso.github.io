Urban & Shop

Tipo de proyecto:

Aplicación web / Landing page e-commerce (Frontend)

Descripción del proyecto

Urban & Shop es un proyecto de e-commerce frontend desarrollado para una marca de moda reciclable, enfocado en la presentación de productos y la simulación de un flujo de pago en línea. El objetivo fue construir una interfaz funcional y clara, integrando una pasarela de pagos en modo sandbox para validar el proceso de compra desde el frontend.

Mi aporte

Desarrollé la estructura frontend del proyecto utilizando HTML, CSS y JavaScript, organizando la arquitectura del sitio y los componentes principales. Implementé la integración de la pasarela de pagos de Mercado Pago en entorno sandbox, simulando el flujo de pago sin backend, y trabajé el diseño y la experiencia de usuario para garantizar una navegación clara y responsive.

Tecnologías utilizadas

HTML, CSS, JavaScript, APIs REST, Mercado Pago (Sandbox), UX/UI

Resultado / Aprendizaje

El proyecto reforzó mi comprensión del consumo de APIs externas desde el frontend, la integración de servicios de pago en entornos de prueba y la importancia de una arquitectura clara en aplicaciones web, diferenciando responsabilidades entre frontend y backend.

MindBridge con Agente de Inteligencia Artificial

Tipo de proyecto:

Aplicación web / Landing page interactiva

Descripción del proyecto

Landing page desarrollada para un servicio de psicología, orientada a evaluar el estado emocional del usuario mediante una experiencia interactiva. El objetivo del proyecto fue ofrecer una primera aproximación digital que guiara al usuario a través de preguntas estructuradas y generara una respuesta orientativa en tiempo real.

Mi aporte

Desarrollé la interfaz frontend y la lógica de interacción de la landing page, integrando un agente de inteligencia artificial capaz de procesar las respuestas del usuario y generar una evaluación básica del estado de ánimo. Me enfoqué en la claridad de la experiencia, el flujo de preguntas y la correcta comunicación de resultados al usuario.

Tecnologías utilizadas

HTML, CSS, JavaScript, APIs REST, Integración de IA, UX/UI

Resultado / Aprendizaje

Este proyecto fortaleció mi experiencia en la integración de servicios inteligentes dentro de aplicaciones frontend, así como el diseño de flujos conversacionales y experiencias orientadas al usuario, combinando lógica, diseño y funcionalidad.

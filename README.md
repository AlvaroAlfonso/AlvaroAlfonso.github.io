🌐 Portafolio Web — Álvaro Alfonso

Este repositorio contiene el código fuente de mi portafolio web personal, donde presento proyectos reales desarrollados en frontend, diseño UX/UI, soluciones no-code/low-code y aplicaciones móviles.
El objetivo del portafolio es mostrar cómo pienso, cómo diseño y cómo ejecuto productos digitales, más allá del resultado visual.

👨‍💻 Sobre mí

Soy Frontend Developer Jr con enfoque en UX/UI, con experiencia construyendo interfaces web funcionales, integrando APIs REST y aplicando principios de usabilidad y diseño centrado en el usuario.
He trabajado en proyectos reales utilizando HTML, CSS, JavaScript, frameworks como React y Angular, así como herramientas no-code/low-code (WordPress, Webflow) y desarrollo mobile con FlutterFlow.

Mi perfil combina ejecución técnica + criterio de diseño, orientado a startups, agencias digitales y equipos de desarrollo.

🧱 ¿Qué encontrarás en este portafolio?

El portafolio está organizado en cuatro bloques principales:

🔹 Proyectos Full Stack (Frontend)

Proyectos desarrollados principalmente con código, enfocados en la construcción de interfaces web sólidas y la integración de servicios externos mediante APIs REST.
Ejemplos:

* E-commerce frontend con integración de pasarela de pagos (Mercado Pago – modo sandbox)
* Landing page interactiva con agente de inteligencia artificial

🔹 UX/UI & Prototipos

Proyectos de diseño, prototipado y documentación UX, enfocados en análisis de usabilidad, arquitectura de la información y validación de experiencias antes del desarrollo.
Incluye análisis aplicando heurísticas de Jakob Nielsen y prototipos web y mobile realizados en Figma.

🔹 No-Code / Low-Code Solutions

Sitios web y landing pages desarrollados con WordPress y Webflow, orientados a negocios e instituciones, priorizando rapidez de ejecución, claridad del contenido y experiencia de usuario.

🔹 Aplicaciones Móviles

Aplicaciones móviles desarrolladas con FlutterFlow, integrando flujos de usuario, bases de datos y sistemas de autenticación, orientadas a resolver necesidades reales.

🛠️ Tecnologías principales

- Frontend: HTML, CSS, JavaScript
- Frameworks: React, Angular
- UX/UI: Figma, Diseño centrado en el usuario, Heurísticas de Jakob Nielsen
- APIs: Consumo de APIs REST, integraciones externas
- No-Code / Low-Code: WordPress, Webflow, FlutterFlow
- Herramientas: GitHub, Metodologías ágiles (Scrum)
